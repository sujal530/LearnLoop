# 🚀 LearnLoop AI

> **Your AI Mentor That Learns With You**

LearnLoop AI is an AI-powered learning mentor that creates personalized learning roadmaps, generates daily study tasks, answers learner doubts using AI, tracks progress, and continuously adapts learning plans based on performance.

Developed for **Hack Better Than Me (HBTM) Hackathon 2026**

---

# 📖 Overview

Traditional learning platforms recommend content.

LearnLoop AI acts as an intelligent mentor that understands the learner's goals and guides them throughout their learning journey.

Instead of watching random tutorials, learners receive:

- Personalized Roadmaps
- Daily Learning Tasks
- AI Mentor Support
- Quiz Generation
- Progress Analytics
- Learning DNA
- Smart Feedback Loop

---

# ✨ Features

## 🎯 Goal Intake

Users enter:

- Learning Goal
- Skill Level
- Daily Study Time
- Deadline

The AI creates a personalized learner profile.

---

## 🗺 Dynamic Learning Roadmap

Generate personalized weekly learning roadmaps.

Roadmaps adapt based on:

- Quiz Performance
- Progress
- Missed Tasks
- Study Consistency

---

## 📅 Daily Task Generator

Weekly plans are divided into manageable daily tasks.

Examples:

- Learn Variables
- Practice Loops
- Build Mini Project
- Solve Quiz

---

## 🤖 AI Mentor

Powered by Google Gemini AI.

Features include:

- Explain Concepts
- Solve Doubts
- Generate Notes
- Create Quizzes
- Give Examples
- Learning Suggestions

---

## 📝 Quiz Generator

Generate AI-powered quizzes.

Supports:

- Multiple Choice Questions
- Difficulty Levels
- Instant Score
- Feedback

---

## 📊 Progress Dashboard

Track:

- Completion Percentage
- Study Hours
- Streak
- Weekly Progress
- Total Tasks
- Completed Tasks

---

## 🧬 Learning DNA

Measures learner quality using:

- Consistency
- Confidence
- Understanding
- Quiz Performance
- Learning Speed

---

## 🔄 Feedback Loop

Quiz performance updates:

- Roadmap
- Tasks
- Revision Topics
- Weak Areas

---

## 🔔 Smart Nudges

Provides reminders based on:

- Pending Tasks
- Missed Days
- Upcoming Deadlines

# 📦 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/LearnLoopAI.git
```

Move into project folder

```bash
cd LearnLoopAI
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the project

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
